IDAT7215 · 期中复习资料准备中

这个页面已经建好，等你把资料发给我，我就把「讲义精讲 + 概念速记 + 模拟卷（含解析）」填进来。

这门课准备怎么做

  • 把每节课的 slides 按课堂顺序讲透：这页在讲什么、为什么重要、和考试怎么挂上钩
  • 把音频摘要里老师反复强调的内容抽成「老师强调点」清单，与 slides 对齐（老师强调的通常就是考点）
  • 把知识点做成概念卡：定义 / 为什么 / 例子 / 易混点，配知识地图（模块 → 概念 → 公式）
  • 从往届试卷反推题型、分值、出题习惯，按同样的风格出模拟卷，每题给「答案 + 解析 + 对应讲义哪一页」
  • 学-测闭环：每讲完一个模块立刻小测；错题自动进错题本，按遗忘曲线安排复习

需要你发的资料

  • 前几次课的 slides（PDF / PPT 都行，一次全发也可以）
  • 课堂音频摘要（文字稿或录音都行；文字稿更快）
  • 往届试卷（有几套发几套，最好含答案或评分点）
  • 期中考试信息：日期、范围（考哪几讲）、时长、开卷还是闭卷、题型与分值占比
