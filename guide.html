怎么用

三种身份，三条路径。先看你是不是「只想复习的同学」。

一、只想复习

1. 打开课程，直接学

1
在首页点你的课程卡片（不需要注册、不需要登录）。
2
先做 12 题摸底（约 8 分钟）：它会告诉你哪几讲可以少花时间。
3
之后每天点一次 今天学 20 关：读一小段 → 立刻做一题 → 错题第二天先清。
4
考前切到 真题：按考点重组的那篇先读，再逐卷看拆解。

进度存在你这台设备的浏览器里。换设备时在课程页「⋯ → 同步设置」配置（需要你自己的私有仓库）。

二、想给一门新课「做成课」

先说实话：生成必须发生在网页之外

这个站是纯静态页面（GitHub Pages），没有服务器、没有模型密钥。所以「拖进 PPT 就自动生成」在浏览器里做不到——生成需要 AI + Python。能在线完成的只有两件事：导入和分享。

路径适合谁怎么做耗时
A. 交给 Hermes
最快		你（有 Hermes / 有我这个助手）把 slides 和往年卷发我，说「按 slides-to-course 做成课」。我跑技能：提取 → 并行写讲义题库 → 校验 → 构建 → 发布。1 份约 10 分钟
10 份约 30 分钟
B. 用任意 AI 生成没有 Hermes、但有 ChatGPT / Claude下载 PROMPT.md，连同课件一起发给 AI；拿它产出的文件，用 pack_course.py 校验打包。20–40 分钟（看课件量）
C. 直接用别人做好的只想省事下载 .pack.json，在首页「我的课程（本机）」→ 导入。30 秒

路径 A 的具体话术（可直接复制）

把这几份 slides 做成学习中心的课程：
- 文件：/path/to/slides.pdf（共 N 讲）
- 考试：12 月期末，60 分钟，闭卷，选择 + 简答
- 有往年卷：/path/to/pastpaper.pdf
按 slides-to-course 技能跑，做完给我网址。

没有往年卷也能做，只是「真题」页会空着——题库密度会明显低于有卷子的课。

三、想自己跑整套流程（开发者）

依赖与命令

Python 3.10+，pip install pymupdf。不需要 Node、不需要数据库。

# 1. 新建课程目录
cp -r templates/course-template courses/my-course

# 2. 放课件后，让 AI 按 PROMPT.md 产出
#    weeks/w1/{精讲.md, 概念卡.md, bank_week1.json}

# 3. 校验 → 生成关卡 → 构建
python pack_course.py courses/my-course --check
python tools/make_study.py courses/my-course
python app/build_course.py courses/my-course

# 4. 打成可分享的单文件数据包
python pack_course.py courses/my-course --pack-json

产物：courses/<id>/index.html（单文件课程页）+ <id>.pack.json（可导入、可转发）。

为什么不做成「网页里一键生成」？三条路都要额外成本：① 后端 + API key：需要一台常开的服务器，而且模型生成题目会出错（考试场景不能出错）；② GitHub Action 触发：要把 key 放进仓库 secrets，跑一次几分钟，还得处理并发；③ 纯前端小模型：质量不够，数学/代码题容易编错。
现在的分工是：生成离线、校验自动、内容可复查、站点纯静态——换来的是「电脑关机也能用、不花钱、不会突然挂」。
